Administration des accès — rôles de la plateforme

Trois rôles distincts. Les comptes admin se paramètrent section par section (écran 07) ; les comptes formateurs ouvrent le dashboard formateur (D), avec ou sans le volet coaching privé.

Administrateur
Dashboard admin complet, sections cochées une à une à la création du compte (écran 07). Le référencement se sépare en deux droits : « contenu » pour les Titles, meta descriptions et partages, « réglages avancés » pour les slugs publiés, l'indexation et les canonicals. Double vérification à la connexion.
Formateur simple
Dashboard formateur : vue d'ensemble, profil public, modules & inscriptions, sessions de coaching, profils des apprenants concernés, revenus. Pas de coaching privé.
Formateur avec coaching privé
Tout l'accès Formateur simple + section Coaching privé : demandes le concernant, sujets soumis par les apprenants, séances planifiées, revenus coaching (50 000 FCFA/h). Profil proposé au coaching sur /formateurs.
